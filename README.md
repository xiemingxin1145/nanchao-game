# 《南北朝》— 2.5D 回合制历史策略游戏

> 乱世英雄起四方，谁主沉浮定乾坤。

《南北朝》是一款以公元 420–589 年中国南北分裂时期为背景的 **2.5D 回合制历史策略游戏**。玩家扮演一方诸侯，通过内政经营、军事征伐、外交纵横，最终统一天下。

## ✨ 游戏特色

- **历史还原**：16 座南北朝历史名城、15 位历史名将（高欢、宇文泰、韦孝宽、陈霸先等）
- **完整内政**：征兵（步/骑/弓三兵种克制）、农业、商业、防御、太守任命、税率调节
- **深度战斗**：兵种克制 × 武将属性 × 地形加成 × 城防 × 补给状态综合演算
- **外交纵横**：同盟、停战、策反、进贡
- **事件系统**：天灾、瘟疫、丰收、蛮族入侵、叛乱 + 历史事件（侯景之乱、河阴之变等），含 2.5D 插画与选项
- **2.5D 美术**：等距视角伪 3D 大地图，25 张 AI 生成的古风插画（武将立绘/战斗/事件/标题）
- **存档系统**：3 个手动存档位 + 自动存档

## 🎮 快速开始

### 方式一：下载安装包（推荐）

前往 [Releases 页面](https://github.com/xiemingxin1145/nanchao-game/releases) 下载 `NanChao-1.0.0.AppImage`：

```bash
chmod +x NanChao-1.0.0.AppImage
./NanChao-1.0.0.AppImage
```

> 如提示缺少 FUSE：`sudo apt install libfuse2`（Debian/Ubuntu）或 `sudo dnf install fuse`（Fedora）

### 自动更新

游戏内置自动更新系统：**启动时自动检查 GitHub 新版本**，发现更新后在后台差分下载（只下载变化部分），下载完成弹窗提示，一键重启即完成升级——无需删除旧安装包，**存档不会丢失**。之后每 30 分钟自动检查一次。

### 方式二：源码运行

```bash
npm install
npm start
```

**系统要求**：Linux x86_64，内存 2GB+，分辨率 1024×768+

## 🕹️ 玩法速览

- 可选势力：**南朝·梁**（经济强、据长江天险）/ **东魏**（人口最多、骑兵强）/ **西魏**（地形险固、步兵精锐）
- 点击己方城市：征兵、发展农业/商业、修缮防御、任命太守、调整税率
- 点击己方军队：移动、攻击、解散、任命武将
- **胜利**：控制全部 16 座城市；**失败**：都城被攻占
- 单局时长：约 30–60 分钟

详细操作见 [安装与运行说明.md](安装与运行说明.md)，完整设计见 [GDD_立项说明.md](GDD_立项说明.md)。
